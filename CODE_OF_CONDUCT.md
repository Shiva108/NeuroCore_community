# Code of Conduct

## Expectations

Contributors are expected to:

- be respectful and professional
- give technical feedback directly and constructively
- assume good intent while still holding a high engineering bar
- keep discussions focused on improving the project

## Unacceptable Behavior

The following is not acceptable:

- harassment, intimidation, or personal attacks
- discriminatory or abusive language
- publishing private information without permission
- disruptive behavior that blocks productive collaboration

## Maintainer Responsibilities

Maintainers may edit, remove, or reject comments, issues, pull requests, and
other contributions that violate this code of conduct.

## Reporting

Report conduct issues privately to the maintainer. Public callout threads are
not the preferred channel for moderation issues.
