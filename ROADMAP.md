# Roadmap

## Near-Term Public Goals

- keep the core package stable across CLI, HTTP, and MCP surfaces
- improve public onboarding and local-first developer setup
- grow community-safe examples and contract-level tests
- harden repo validation and release automation for curated public drops

## Contribution Opportunities

- test coverage for edge cases in capture, query, and storage behavior
- docs improvements for public workflows and adapter usage
- performance and ergonomics improvements that preserve public contracts
- generic examples built on the shipped package surfaces

## Intentionally Non-Public Areas

- private development history and internal planning notes
- proprietary workflows, research materials, and operational runbooks
- provider-specific deployment or integration packages that are not ready for
  community support
