# Skill Template

Use a `kebab-case` directory name for each skill. A valid skill folder must
contain `README.md`, `metadata.json`, and `SKILL.md`, and `make validate` or
`python scripts/validate_checkout.py` is the required gate before you treat the
skill as ready.

## What it does

Describe the reusable operator or agent behavior this skill enables.

## Supported Clients

- Codex
- Claude Code

## Installation

Place the skill artifact in the client-specific skills directory and keep the
checked-in source as the canonical copy.
