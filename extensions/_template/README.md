# Extension Template

Use a `kebab-case` directory name for each extension. A valid extension folder
must contain `README.md` and `metadata.json`, and `make validate` or
`python scripts/validate_checkout.py` is the required gate before you treat the
contribution as ready.

## What it does

Describe the higher-level capability this curated extension adds on top of the
NeuroCore core package.

## Prerequisites

- Working NeuroCore reference stack

## Steps

1. Explain the runtime, storage, and adapter requirements.
2. Document the setup sequence.
3. Explain how to validate the finished result.

## Expected Outcome

Describe what users should see when the extension is working.
