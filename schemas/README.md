# Schemas

Open contribution surface for supplemental schema patterns and storage
extensions that build on the NeuroCore core model.

The checked-in HTTP adapter contract snapshot lives at
[`schemas/neurocore-http-openapi.json`](./neurocore-http-openapi.json). Regenerate
it with `python scripts/generate_openapi_snapshot.py`.

Start from [`schemas/_template/`](./_template/).
